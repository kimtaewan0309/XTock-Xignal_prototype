# StockSimulationSection.jsx
1. 시작/초기화
1) 처음 실행 시, '초기 가상 자금' (기본값 5000) 주어짐
2) '시뮬레이션 시작' 버튼 누르면 거래 가능
3) '계좌 초기화' 버튼 누르면 가상 자금이 초기 금액으로, '보유 종목'/'거래 내역' 모두 삭제

2. 종목 조회
1) 티커 입력 후, '조회' 버튼 누르면 프론트엔드가 서버의 /api/recent-status로 요청 전송
2) 시뮬레이션 전용으로 stock_history_days도 같이 전송
3) 서버는 yfinance 기준 날짜별 시가, 종가, 고가, 저가, 거래량 데이터를 stock_data 배열 형태로 반환

3. 차트
1) 선그래프, 이평선, 캔들차트 중 선택해 볼 수 있음
2) 슬라이더나 이전/다음 버튼으로 특정 날짜 선택 (selectedDayIndex 변경)
3) 현재가 = 선택한 날짜의 종가

4. 매수
1) 선택한 날짜의 종가 기준
2) 매수 금액 = 종가 x 수량
3) 가상 현금 감소, 보유 수량 증가
4) 평균 단가 = (기존 평균단가 x 기존 수량 + 이번 매수 금액) / (총 수량)

5. 매도
1) 선택한 날짜의 종가 기준
2) 매도 금액 = 종가 x 수량
3) 가상 현금 증가, 보유 수량 감소
4) 실현 손익 = (매도가 - 평균 단가) x (수량)으로 총 손익에 반영

6. 계좌 총액
1) 계좌 총액 = 가상 현금 + 보유 주식 가치
2) 보유 주식 가치 = 선택한 날짜의 종가 x 수량

7. 손익
1) 실현: 이미 매도하여 확정된 이익/손실
2) 미실현: 아직 보유 중인 주식의 평가 손익 ((현재 단가 - 평균 단가) x (수량))
